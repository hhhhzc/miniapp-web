# 广告入口与活动二级页

每个入口独立选择打开方式。直接跳转继续使用现有目标；活动页流程为：首页广告图 → 本小程序活动页 → 用户点击领取按钮 → 微信确认 → 目标小程序。页面加载时不自动拉起目标。

## 后台配置

1. 进入管理后台，选择模块，新增或编辑入口。
2. 跳转方式选择“打开微信小程序”，填写联盟或目标平台提供的真实 AppID、页面路径、附加参数。
3. 打开方式选择“先进入活动页，再点击按钮前往”。选择“直接打开目标小程序”则保持原流程。
4. 活动页复用入口标题和简介。可上传独立详情图，或留空沿用入口图；填写活动说明和按钮文字，保存。
5. 小程序重新进入首页或下拉刷新后生效。旧入口默认直接打开，不需要逐个重新保存。

活动说明为纯文本，支持换行。游客可以查看活动并点击目标，不要求先登录。页面路径留空只会打开目标小程序首页；要进入优惠活动，需配置平台提供的有效活动路径。

## 数据库升级

- 新数据库：使用后端 db/schema.sql。
- 已有本地 H2：使用 local 配置启动后端，自动补齐新列，不清空数据。
- 已有 MySQL：部署新版后端前，执行后端 app/src/main/resources/db/migrations/20261119_entry_activity.sql 一次。新库无需重复执行迁移。

接口新增 GET /api/v1/home/entries/{id}。只有启用入口及启用模块下的内容能公开读取，停用或删除后返回 404。二级页每次显示时重新加载，加载失败会清除旧内容并提供重试。

## 本地验证

前端：`npm test`、`npm run build:mp-weixin`、`npm run build:h5`、`npm run build:admin`。

后端：使用 JDK 21 或兼容的更高版本运行 `mvn test`，编译目标保持 Java 21。接口测试覆盖旧请求默认值、活动内容保存与更新、下架不可访问、非法配置及本地旧库升级。

真机验收：

1. 配置一个直接入口和一个活动页入口，使用相同的真实目标 AppID 和路径。
2. 直接入口应发起原有的微信小程序跳转；活动页入口应先显示本小程序的详情页，不弹出目标跳转确认。
3. 点击活动页按钮，确认打开目标后，检查实际到达的活动页；取消后应可继续操作。
4. 返回首页、编辑活动内容，重新进入检查更新。测试无详情图时沿用入口图、无图片时展示备用图标。
5. 停用入口或模块后，重新进入二级页应提示活动不可用，不再展示旧领取按钮。

H5 可用于查看活动页布局；实际跨小程序跳转需在微信真机验证，开发者工具和网页预览不能代替此项验收。
